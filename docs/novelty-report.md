## 結論

**作成する。**

HashMapを扱う近接記事は確認できましたが、`getOrDefault`の**nullマッピングが既定値を返さない**ことを直接原因として、解決値・最後の解決値・既定利用件数を扱う記事・教材は見つかりませんでした。

既存の可変キー記事とは、キーのハッシュ安定性か、値のnull正規化かが異なります。実境界、観測契約、最小修正も独立しているため、教育上意味のある追加題材と判断しました。
